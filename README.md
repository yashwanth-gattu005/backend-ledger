# Backend Ledger Management System

Backend API for a ledger management system built with Node.js, Express.js, and MongoDB.

## Features

- User authentication with JWT
- Secure password hashing with bcrypt
- Account management
- Transaction management
- Ledger management
- Protected API routes
- Email service integration
- MongoDB database integration

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Nodemailer
- dotenv
